Changed paths require focused tests for endpoint assignment/DNS, independent policies, all-five-protocol URI/YAML/JSON/QR round-trips, real generated-profile traffic, network UI and subscription authorization, legacy upgrades, HTTPS listener/firewall transaction rollback and native backup restoration. Public bootstrap acceptance must use the real anonymous new-repository URL, pinned TAR and controlling terminal in the disposable environment.

Unchanged hardened core and accounting contract retain prior valid evidence. Historical performance/soak/device evidence is not presented as newly executed. CLI import and packet acceptance do not imply physical mobile/desktop device tests. Native online IPv6-only bootstrap is not inferred from staged archive installation. A/B live installations are not upgraded or restarted without separate authorization.
