# Distributed third-party notices

MANIFEST.json maps the distributed module notices. Original names, version identifiers and license contents are retained as provenance; they are not placeholders requiring cosmetic renaming for each SBOX release.

The modified accounting core's corresponding source, patch, upstream tag and reproducible build are described in [core-source/README.md](../core-source/README.md). Common web assets retain their notices under shared_webui/licenses. [Release metadata](../assets/release.json) identifies the exact current components.
